## Описание проекта
Brain games это небольшой pet-проект по функционалу состоящий из 5 простых математических игр.
Реализован полностью в функциональном стиле без применения ООП и классовой парадигмы. 

### Правила
Одержать победу в каждой из игр можно 3-мя последовательными победами в каждом из раундов.
Неправильный ответ завершает игру неудачей.
